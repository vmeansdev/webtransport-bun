# 1.0.0 Release Status

Canonical release truth: `docs/release-status.json`.

Package version: `1.0.0-rc.1`.

Current state: both the native root entrypoint and `/wasm` are candidate
surfaces. Neither surface is stable or GA, and the manifest is still pending.

The current closure plan says the local implementation work for Tasks 1-16 is
largely landed, but review fixes are still moving on Tasks 7/8, 13, 14, and 15.
The remaining release gates are still external and still pending: immutable
candidate SHA, cross-platform/runtime CI, coverage, fuzz campaign,
>=10k diverse-source scale, package/provenance, 24h/72h soak, zero P0-P4
eight-lane review, and final no-change confirmation.

## What is safe to say today

- The package is still `1.0.0-rc.1`.
- The current release manifest is still the source of truth and still pending.
- The native and wasm implementation surfaces have landed far enough to carry
  local tests, but release verification is not complete.
- The IWA and browser interop evidence exists as workflow artifacts, but it is
  not a release claim until it is bound to the candidate SHA in
  `docs/release-status.json`.
